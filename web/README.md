# GifCapture Web

브라우저에서 화면을 녹화하고, 프레임을 편집해서, GIF로 저장하는 웹 앱입니다. Windows 데스크톱 앱([GifCapture](../README.md))과 같은 기능을 설치 없이 쓸 수 있습니다.

**바로 쓰기: https://zodiacray.github.io/gif-capture/**

**영상과 GIF는 이 브라우저 안에서만 처리됩니다. 서버로 전송되지 않습니다.** 서버가 없는 정적 사이트입니다.

## 기능

**녹화**
- 화면, 창, 탭 중 하나를 골라 녹화합니다. 선택은 브라우저가 띄우는 창에서 합니다.
- 고른 화면 위에서 **녹화할 영역을 크기 조절 핸들로 지정**합니다 (가장자리·모서리를 끌어 크기 조절, 안쪽을 끌어 이동, px 직접 입력)
- fps, 타이머(정한 시간 뒤 자동 종료), `F7` 시작/정지
- 브라우저의 "공유 중지" 버튼을 누르면 그때까지 녹화한 내용으로 편집기가 열립니다.

**편집**
- 프레임 목록 (번호와 지연 시간 표시, 클릭·Shift·Ctrl 선택), 재생 컨트롤, 재생 속도, 반복 재생
- 프레임 삭제, 앞쪽·뒤쪽 프레임 일괄 삭제
- 화면 자르기, 글자 추가 (크기·색·위치, 선택한 프레임에만 적용 가능, 여러 줄 가능)
- `Ctrl+Z` 되돌리기 (자르기, 글자 추가, 삭제 모두 지원)

**불러오기 / 저장**
- 기존 GIF를 불러와서 같은 방식으로 편집합니다 (버튼 또는 창에 끌어놓기, 프레임별 지연 시간 유지)
- GIF 저장 (반복 여부, 재생 속도 반영)
- 목표 용량(MB)에 맞춰 크기를 자동으로 줄여 저장

**기타**: 라이트/다크 모드, 설정 기억(브라우저 저장소), 좁은 화면 대응

## 데스크톱 앱과 다른 점

| | 데스크톱 앱 | 웹 버전 |
|---|---|---|
| 녹화 영역 | 화면 위에 투명 프레임을 놓고 지정 | 브라우저로 화면을 고른 뒤 미리보기 위에서 영역 지정 |
| `F7` | 다른 앱에 포커스가 있어도 동작 | 이 페이지에 포커스가 있을 때만 동작. 다른 창을 녹화하는 중에는 브라우저의 "공유 중지" 버튼으로 끝낼 수 있고, 타이머를 쓰면 자동으로 끝납니다. |
| 긴 녹화 | 프레임을 디스크에 저장 | 프레임을 브라우저 메모리에 저장해서 길고 큰 녹화는 부담이 됩니다. |
| 업데이트 | 앱이 알림 | 접속할 때마다 최신 버전 |

화면 녹화는 데스크톱의 Chrome, Edge, Firefox, Safari에서 지원됩니다. 모바일 브라우저는 화면 녹화를 지원하지 않지만 GIF 편집은 가능합니다. 다른 창을 녹화하는 동안 이 탭이 뒤로 가도 프레임이 끊기지 않는 방식(`MediaStreamTrackProcessor`)은 Chrome 계열에서 사용되고, 다른 브라우저에서는 대체 방식을 쓰므로 녹화하는 동안 이 탭이 보이는 상태이면 더 안정적입니다.

## 개발

Node.js 22.12 이상이 필요합니다.

```powershell
cd web
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 인코더·디코더·용량 탐색·광고 규칙 테스트
npm run typecheck  # 타입 검사
npm run build      # dist/ 에 배포용 파일 생성
```

`npm run build`의 결과(`dist/`)는 상대 경로로 만들어져서 어느 하위 주소에 올려도 동작합니다. 서버 설정은 필요하지 않습니다.

## 구조

```
src/
  main.ts            화면 전환, 끌어놓기, 저장 안 한 작업 보호
  views/             home(시작), record(녹화), editor(편집)
  recorder.ts        화면 캡처와 프레임 저장
  cropbox.ts         크기 조절 가능한 영역 상자 (녹화 영역, 자르기에서 공용)
  imaging.ts         프레임 자르기, 글자 그리기, 썸네일
  model.ts           프레임 목록과 되돌리기 기록
  strip.ts, player.ts  프레임 목록, 미리보기와 재생
  storage.ts, theme.ts  기억하는 설정, 라이트/다크
  ads.ts, adsPolicy.ts  선택적 광고와 동의 (설정이 없으면 아무것도 하지 않음)
  gif/
    encoder.ts       GIF 인코더 (색상 줄이기, LZW, 바뀐 부분만 저장)
    decoder.ts       GIF 읽기 (프레임 합성, 처리 방식 3가지 지원)
    sizeSearch.ts    목표 용량에 맞는 크기 탐색
    export.worker.ts 웹 워커에서 인코딩 (화면이 멈추지 않음)
public/              안내 페이지(guide, privacy)와 아이콘
tests/               인코더·디코더·용량 탐색·광고 규칙 테스트
```

프레임은 편집해도 원본을 고치지 않고 새 프레임을 만들기 때문에, 되돌리기는 프레임 목록의 복사본을 되돌리는 것으로 충분합니다.

## 광고 (선택)

기본값은 **광고 없음**입니다. 광고 설정이 비어 있으면 광고, 동의 배너, 관련 문구가 어디에도 나타나지 않습니다. 설정을 넣으면 Google AdSense 광고를 **시작 화면 한 곳**에만 표시합니다. 녹화 화면과 편집기에는 광고가 없습니다.

- 방문자가 **동의하기 전에는 광고 스크립트를 불러오지 않습니다.** 거부하면 광고가 나오지 않고, 푸터의 "광고 설정"에서 언제든 다시 고를 수 있습니다. 동의를 철회하면 페이지가 새로 시작되어 광고 스크립트가 남지 않습니다.
- 광고 설정 값은 코드가 아니라 빌드 때 넣습니다.

| 변수 | 내용 |
|---|---|
| `ADSENSE_CLIENT` | AdSense 게시자 ID (`ca-pub-` 뒤에 숫자) |
| `ADSENSE_SLOT_HOME` | 시작 화면용 광고 단위 ID (숫자) |

GitHub 저장소의 **Settings → Secrets and variables → Actions → Variables**에 위 두 개를 넣으면 다음 배포부터 켜집니다. 로컬에서 시험하려면 `VITE_ADSENSE_CLIENT`, `VITE_ADSENSE_SLOT_HOME` 환경 변수로 같은 값을 주고 `npm run dev`를 실행하세요. 형식이 맞지 않는 값은 "설정 안 됨"으로 취급합니다.

광고를 켜기 전에 확인할 것:
- **승인**: AdSense 승인은 계정과 사이트 심사를 거칩니다. 승인되기 전에는 게시자 ID와 광고 단위가 없습니다. [사용 방법·FAQ](public/guide.html)와 [개인정보처리방침](public/privacy.html) 페이지는 심사에 필요한 기본 내용으로 만들어 두었습니다.
- **도메인과 `ads.txt`**: AdSense는 보통 본인 소유의 도메인을 요구하고, `ads.txt` 파일은 도메인 최상위 주소에 있어야 합니다. 그 파일을 `public/ads.txt`에 넣으면 됩니다(`github.io` 하위 주소로는 최상위에 둘 수 없습니다).
- **EU/영국/스위스 방문자**: 이 사이트의 동의 배너는 단순한 안내이며 Google이 요구하는 인증된 동의 관리 도구(CMP)가 아닙니다. 해당 지역 방문자가 있다면 AdSense의 "개인정보 보호 및 메시지"(Google CMP)를 설정하세요.
- **개인정보처리방침**: 일반적인 내용으로 작성한 안내이므로 운영 형태에 맞게 직접 검토하고 필요하면 고치세요.
- **호스팅 약관**: GitHub Pages는 영리 목적 사이트 운영에 제한이 있습니다. 광고를 켜기 전에 [약관](https://docs.github.com/pages/getting-started-with-github-pages/github-pages-limits)을 확인하거나 다른 호스팅으로 옮기는 것을 검토하세요.

## 배포 (GitHub Pages)

`main` 브랜치의 `web/` 폴더가 바뀌면 [`.github/workflows/pages.yml`](../.github/workflows/pages.yml)이 테스트와 빌드를 한 뒤 GitHub Pages에 올립니다. 처음 한 번은 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다.
