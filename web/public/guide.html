사용 방법

화면을 녹화해서 GIF로 만드는 과정을 단계별로 설명합니다. 설치도 회원가입도 필요 없습니다.

1. 녹화하기

  1. 시작 화면에서 ● 화면 녹화 시작을 누르면 브라우저가 공유할 화면을 묻습니다. 전체 화면, 창, 탭 중 하나를 고르세요.
  2. 선택한 화면의 미리보기가 나타납니다. 파란 상자의 모서리와 가장자리를 끌어 녹화할 영역을 정하고, 상자 안쪽을 끌어 위치를 옮깁니다. 아래 입력칸에 숫자(px)를 직접 넣어도 됩니다.
  3. fps(초당 프레임 수)를 정합니다. 값이 클수록 부드럽지만 용량이 커집니다. 보통 10~15를 권합니다.
  4. 정해진 시간만 녹화하려면 타이머를 켜고 초를 입력하세요. 시간이 지나면 자동으로 멈춥니다.
  5. ● 녹화 시작(또는 F7)을 누르고, 끝내려면 ■ 정지를 누르거나 브라우저의 "공유 중지"를 누릅니다.

2. 편집하기

  • 프레임 삭제: 프레임 목록에서 선택(Shift는 범위, Ctrl은 하나씩 추가)하고 Delete. "앞쪽 삭제/뒤쪽 삭제"로 현재 프레임 앞이나 뒤를 한 번에 지울 수 있습니다.
  • 화면 자르기: 모든 프레임을 같은 영역으로 자릅니다. 핸들을 끌어 영역을 정하고 적용하세요.
  • 글자 추가: 글자, 크기, 색을 정하고 미리보기를 클릭해 위치를 정합니다. 선택한 프레임에만 넣을 수도 있습니다.
  • 재생 속도: 미리보기와 저장되는 GIF의 속도를 함께 조절합니다. 2를 넣으면 두 배 빠릅니다.
  • 되돌리기: Ctrl+Z로 자르기, 글자 추가, 삭제를 되돌립니다.

3. GIF로 저장하기

GIF 저장을 누르면 파일이 내려받아집니다. 용량 제한을 켜고 MB를 입력하면, 그 크기 이하가 되도록 해상도를 자동으로 줄여서 저장합니다. 메신저나 게시판에 올릴 때 파일 크기 제한이 있다면 이 기능을 쓰세요. "GIF 반복"을 끄면 한 번만 재생되는 GIF가 됩니다.

4. 이미 있는 GIF 편집하기

GIF 불러오기를 누르거나 GIF 파일을 창에 끌어다 놓으세요. 프레임별 재생 시간이 그대로 유지되어 같은 방법으로 편집할 수 있습니다.

자주 묻는 질문

녹화한 영상이 서버에 올라가나요?

아니요. 녹화, 편집, GIF 만들기는 모두 내 브라우저 안에서 처리되고 어디로도 전송되지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

어떤 브라우저에서 되나요?

화면 녹화는 데스크톱의 Chrome, Edge, Firefox, Safari에서 지원됩니다. 휴대폰 브라우저는 화면 녹화를 지원하지 않지만, 이미 있는 GIF를 편집하는 것은 가능합니다.

소리도 녹음되나요?

아니요. GIF는 소리를 담을 수 없는 형식이라 화면만 녹화합니다.

GIF 파일이 너무 커요. 어떻게 줄이나요?

① 녹화 영역을 작게 잡고, ② fps를 낮추고(예: 10), ③ 녹화 시간을 짧게 하고, ④ 불필요한 프레임을 삭제하세요. 그래도 크다면 저장할 때 용량 제한을 켜서 목표 MB를 정하면 해상도를 자동으로 줄여 줍니다. 화면 변화가 적은 녹화(예: 글자 위주 화면)는 크기가 훨씬 작게 나옵니다.

녹화 중에 다른 창으로 이동해도 되나요?

네. 다른 창이나 전체 화면을 공유했다면 자유롭게 이동하며 녹화할 수 있습니다. 끝낼 때는 브라우저가 보여주는 "공유 중지"를 누르거나, 타이머를 미리 설정해 두세요. Chrome 계열이 아닌 브라우저에서는 이 탭이 보이는 상태일 때 더 안정적으로 녹화됩니다.

너무 오래 녹화하면 어떻게 되나요?

녹화한 프레임은 브라우저 메모리에 저장됩니다. 영역이 크거나 시간이 길면 메모리를 많이 쓰므로, 긴 녹화는 영역을 줄이거나 나누어서 하세요.

Windows 데스크톱 앱과 무엇이 다른가요?

같은 기능을 설치 없이 쓰는 웹 버전입니다. 데스크톱 앱은 화면 위에 투명 프레임을 놓고 녹화하고 다른 프로그램을 쓰는 중에도 F7이 동작합니다. Windows 앱 받기
